# Industrial Revolution

An electrical tech mod for Minecraft 1.21.1 (NeoForge): generators, cables, machines and power tools.

Inspired by classic tech mods like IndustrialCraft 2, but an independent project: all code, assets,
text and data here are original. See [CLEAN_ROOM.md](CLEAN_ROOM.md) for the rules this repo follows.

Not affiliated with or endorsed by the IndustrialCraft 2 team.

## Building

```
./gradlew build
```

The jar lands in `build/libs/`. `./gradlew runClient` starts a dev client.
